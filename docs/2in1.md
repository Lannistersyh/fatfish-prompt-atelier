# 2合1 合并版（v2.2）

把「提示词工坊」和「1080P 桌宠」合成一个 App：`大肥鱼.app`。
宿主是原 Swift 工坊，桌宠作为 Python/PySide6 子进程由宿主拉起。

```
大肥鱼.app (Swift, ai.local.fatfish.pet)
├─ 提示词工坊面板（WKWebView，原样保留）
├─ 原生 WebP 桌宠对象（不显示，仅给 Bridge 用）
└─ PetProcess ──► python -m pet（1080P 桌宠，素材 1920×1080）
        env: PET_FRAMESEQ=0, DAFEIYU_WORKSHOP_NOTIFY=1
```

## 宿主侧改动

| 文件 | 改动 |
|---|---|
| `Sources/PetProcess.swift` | 新增：拉起/回收桌宠子进程；SIGTERM→3s→SIGKILL；`/tmp/dafeiyu1080.log` 5 MB 滚动；子进程非预期退出回调 |
| `Sources/AppDelegate.swift` | 不显示原生 WebP 桌宠；启动后 0.8s 自动 `showPanel()`；监听从桌宠来的 `togglePanel` 通知；第二次启动的 `showPanel` 只带到前台不切换；不再创建白色鱼状态项（入口并进桌宠托盘）；Dock 菜单精简 |
| `Info.plist` / `build.sh` | 名称改 `大肥鱼`，版本 2.2，产物 `build/大肥鱼.app` |

## 桌宠运行时补丁（dsh-pet-standalone，MIT）

补丁都在 `~/Library/Application Support/dafeiyu1080/runtime/pet/`，共 5 处：

1. **`workshop_bridge.py`（新增，见本仓库 `runtime-patches/pet/`）**
   `CFNotificationCenterPostNotification` 投递 `ai.local.fatfish.togglePanel`，让桌宠点击能开关工坊面板；未设置 `DAFEIYU_WORKSHOP_NOTIFY=1` 时静默。

2. **`window.py::_on_click` 开头**
   点击（非拖动）时先调 `notify_toggle_panel()`，再走原有 Q 弹/旋转逻辑。

3. **`context_menus/registry.py`**
   新增 `workshop` 动作：`ACTION_LABELS["workshop"]="提示词工坊"`、图标 `web`、
   `MenuActionSpec(_build_workshop, available=lambda _pet: _workshop_enabled())`。

4. **`menu_templates/modern-default-v1.json`**
   在 `ojingjing` 后插入 `{"type":"action","id":"workshop","visible":true,"section":"profile"}`。

5. **`overlay_shell.py::_refresh_tray_menu`**
   顶部新增「打开 / 收起提示词工坊」，点击同样发 `togglePanel`；宿主原状态项已删，菜单栏因此只剩桌宠托盘一个图标。

另有两处 Dock 行为修正（`pet/app.py`）：
`_is_workshop_child()` + `_dock_icon_wanted()`，合并模式下强制 `setActivationPolicy:Accessory`，
桌宠不再在 Dock 里多占一个白纸图标（三处调用点统一走该判据）。

## 行为

| 操作 | 效果 |
|---|---|
| 启动 App | 面板自动弹出 |
| 左键点桌宠 | 开关面板（同时播放点击动画） |
| 右键点桌宠 →「提示词工坊」 | 开关面板 |
| 菜单栏 Q 版小人 →「打开 / 收起提示词工坊」 | 开关面板 |
| `⌥⇧P` | 开关面板 |
| 桌宠右键「退出」 | 整个 App 退出（视为一个整体） |
| `⌘Q` | 退出 App 并回收桌宠子进程 |

## 构建 / 安装

```bash
cd ~/科研项目/肥鱼提示词工坊
./build.sh
rm -rf /Applications/大肥鱼.app
cp -R build/大肥鱼.app /Applications/
```

运行时目录必须存在：`~/Library/Application Support/dafeiyu1080/runtime`（Python venv + pet 包 + 素材）。

## 验证清单

- 冷启动：`pgrep -f FatFishPrompt` = 1、`pgrep -f "python -m pet"` = 1、面板窗口存在
- 通知：连发两次 toggle，面板窗口 1→0→1
- 退出：`⌘Q` 后两进程均 0；重启恢复 1+1
- Dock / 菜单栏：各只剩 1 个图标（鱼 / Q 版小人）
- 日志：桌宠日志 `ERROR/WARNING=0`，`帧长度异常=0`，素材 106 段
- 二次启动：面板已开时不会被误收起（`showPanel` 语义）
